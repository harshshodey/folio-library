# Contributing to Folio

Issues and pull requests are welcome. Describe the problem and the expected behavior, then keep the change focused.

1. Fork the repository and create a branch.
2. Run npm test (Node.js 18+; no package installation required).
3. For C++ changes, compile with C++17 and run folio --self-test.
4. Check desktop and mobile layouts for interface changes.
5. Open a pull request explaining the change and how you verified it.

Use fictional member data in tests and screenshots. Do not commit browser exports, library data files, credentials, or environment files. Include author, work, location, and a verifiable original-text source for any literary excerpt. Preserve clear, direct language for errors and destructive actions.

By contributing, you agree that your original contributions are available under the MIT license.
